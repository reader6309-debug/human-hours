# Human Hours

A 3D online museum for English 11, Q1 Summative 2 (Lost Generation Museum Project).

Six rooms ask one question: is Gen Z a lost generation? Each room compares human time with machine time and plays the curator's own audio guide.

- Curator, artifacts, explanations and voice: Henry
- 3D site code and visuals: built with Claude (AI). No explanation text was written by AI.

Open the museum: https://reader6309-debug.github.io/human-hours/

Songs play as short 60-second clips. Sources for every artifact and song are listed in each room and on the exit wall.
